Tools

Each one follows your live Omarchy theme.

flyoverv0.2.0 · Rust

A real-time ADS-B radar scope for your terminal, with fading trails and a native Omarchy screensaver.

cargo install flyover

flyover-pillQML

An ambient aircraft-count widget for the Omarchy bar. Click for the scope.

omarchy plugin add https://github.com/linuxbren/flyover-pill.git --enable

tidefilesGo

A keyboard-first terminal file manager: three panes, inline image previews, trash with undo.

github.com/linuxbren/tidefiles
