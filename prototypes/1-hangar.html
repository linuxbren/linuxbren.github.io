The workshop

All open source, all terminal-native, all follow your live Omarchy theme.

flyover v0.2.0

A real-time ADS-B radar scope in your terminal. Sixel or braille rendering, fading trails, and a native Omarchy screensaver.

cargo install flyover source →

flyover-pill

An ambient aircraft-count pill for your Omarchy bar. Left-click opens the scope, right-click toggles the screensaver.

omarchy plugin add https://github.com/linuxbren/flyover-pill.git --enable source →

tidefiles

Keyboard-first terminal file manager. Three panes, real inline image previews, trash with undo, follows your theme.

git clone github.com/linuxbren/tidefiles source →
