console-places

v0.13.0 · Go

A keyboard-first, three-pane file manager for your terminal. Previews code, images, video, markdown and spreadsheets in the pane, keeps your bookmarks, drives, phones, Tailscale computers and frequent folders right in the file list, bulk-renames with a live preview, and follows your Omarchy theme. Optional Nerd Font file-type icons. (Formerly tidefiles.)

arch=amd64   # or arm64
curl -L https://github.com/linuxbren/console-places/releases/latest/download/console-places_linux_$arch.tar.gz | tar xz console-places
install -Dm755 console-places ~/.local/bin/console-places

Linux only, x86_64 or arm64. Static binary, updates itself. Packages and Nix too — see the repo.

New in v0.13.0: Phones in places — Android (MTP), iPhone (AFC, with photos/media plus App documents) and cameras (gphoto2) show under Phones; enter mounts, u/d ejects. Needs gvfs-mtp / gvfs-afc + usbmuxd / gvfs-gphoto2.

flyover

v0.3.1 · Rust

A real-time ADS-B radar scope in your terminal. Live aircraft from adsb.lol on an old-school sweep, with range rings, fading trails and data tags. Also runs as a native Omarchy screensaver, taking over your idle screen.

cargo install flyover

Set a location with omarchy-weather-location first.

flyover-pill

Omarchy plugin · QML

An ambient aircraft count for your Omarchy bar, always visible and always current. Left-click opens the live flyover scope in a terminal; right-click toggles flyover's screensaver on or off. Every number it shows comes straight from flyover.

omarchy plugin add https://github.com/linuxbren/flyover-pill.git --enable
omarchy bar put bren.flyover --section right

Needs flyover installed first.
