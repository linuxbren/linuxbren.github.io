flyover

v0.1.0

A real-time ADS-B radar scope, in your terminal. Live aircraft positions from adsb.lol, rendered as an old-school radar sweep — range rings, fading comet trails, per-contact data tags — with two render modes: an off-screen rasterizer with real phosphor glow via Sixel graphics, or a fast character-based fallback that animates smoothly everywhere. Reads your live Omarchy theme colors, so it always matches whatever theme you're running.

cargo install flyover
