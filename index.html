tidefiles

v0.7.0 · Go

A keyboard-first, three-pane file manager for your terminal. Previews code, images and markdown right in the pane, browses inside zip and tar archives like ordinary folders, sends deletes to a real trash with undo, and follows your Omarchy theme.

arch=amd64   # or arm64
curl -L https://github.com/linuxbren/tidefiles/releases/latest/download/tidefiles_linux_$arch.tar.gz | tar xz tidefiles
install -Dm755 tidefiles ~/.local/bin/tidefiles

Linux only, x86_64 or arm64. Static binary, updates itself. Packages and Nix too — see the repo.

flyover

v0.3.1 · Rust

A real-time ADS-B radar scope in your terminal. Live aircraft from adsb.lol on an old-school sweep, with range rings, fading trails and data tags. Also runs as a native Omarchy screensaver, taking over your idle screen.

cargo install flyover

Set a location with omarchy-weather-location first.

flyover-pill

Omarchy plugin · QML

An ambient aircraft count for your Omarchy bar, always visible and always current. Left-click opens the live flyover scope in a terminal; right-click toggles flyover's screensaver on or off. Every number it shows comes straight from flyover.

omarchy plugin add https://github.com/linuxbren/flyover-pill.git --enable
omarchy bar put bren.flyover --section right

Needs flyover installed first.
