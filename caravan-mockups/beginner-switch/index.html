Optimizations

Show more settings
Off keeps this page simple: Self-tuning, one Tune for speed button, Load and Unload, and the safety notices. Caravan keeps using the settings it already learned — nothing is reset. Turn this On any time to see Auto-tune, the tuning rows, Apply & restart, and the other controls again.
Self-tuning
Caravan learns from your chats and remembers faster settings for each model. Pinned choices stay yours.
Tries different settings on the loaded model right now and keeps the fastest. While it runs, only the Tuning badge is shown. Turn Show more settings On to pause, cancel, or reset tuning.
Auto-tune
Tries different settings on the loaded model right now and keeps the fastest.
Run a fresh trial on the loaded model. Works whether Self-tuning is on or off. You do not need to remove or redownload the model.
Clear saved tuning for this model and this setup. The model stays loaded.
Guess-ahead
A smaller model guesses upcoming words for the main MLX model to check. Needs a matching helper on this Mac (one Mac or a split). In our split-model tests, writing one reply was up to ~33% faster; two chats can be slower.
A smaller model of the same family guesses upcoming words for the main model to check. It is often faster on code edits and repeated text and helps less on short chats, and the first word on long prompts can come a little later. Gains vary by model and Mac. Auto uses it only when a test on your model finds it faster. On needs a small helper of the same family on this Mac; when Caravan knows one, it offers it under the model and will not download one for you without your OK.
Prompt lookup (experimental)
Reuse words from your prompt to help the MLX model write repeated text. Up to ~44% faster in our tests on repeated text, but slower on mixed chats; one chat at a time.
Reuse words from your prompt to help with repeated text. Often much faster when the reply repeats the prompt (for example whole-file code edits), little change on short chats, and slightly slower on long prompts. Gains vary by model. Auto stays off until a test finds it is faster.
Shared start (trim / rebuild)
Reuse the beginning of repeated system prompts so the model has less to read. MLX models only.
Reuse the start of a chat so later turns begin sooner.
Two chats
Let two chats use different Minis at the same time when an MLX model is split. Up to ~70% more combined output in our tests without a helper; no gain on one Mini, and slower with a helper.
Let two chats share the model at the same time. Auto keeps one chat.
Context
How much of the conversation the model can keep in mind at once. Auto uses the longest context that fits in memory, up to the full context the model was trained for. Native is that full context.
Fused kernels
Combine small GPU steps when running an MLX model. Experimental — no meaningful speed gain in our tests; some models are incompatible.
Memory compression
Store MLX chat memory more compactly to save RAM; 16 leaves it uncompressed. May lower quality and slow reading; not supported by every model or Native MTP.
Store the chat's working memory more compactly. Auto uses the lighter option only when the full one will not fit with the longest context. Pinning 16 can make Auto pick a shorter context.
GPU keep-warm
Keep the main GPU warm while it waits for another Mini. Split MLX models only; up to ~50% faster writing replies in our tests.
Flash attention
A faster way to read the chat so far. Leave on unless a test says off.
Prompt batch
How much of a long question the model reads at once. Larger can read faster and uses more working memory.
